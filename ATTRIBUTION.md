# Third-party assets

Every image, font, icon, and sound file in RemixRelay that we didn't make
ourselves, where it came from, and the license it's used under. Add a row
whenever you add an asset. Check this list before any public release (the
demo, Devpost, a deployed site).

Most of the Frutiger Aero look (sky, bubbles, glass, gloss) is drawn with CSS
in `src/index.css`, so it has no asset to credit.
